# 功能介紹

[回專案首頁](../README.md) · [Windows 安裝指南](quickstart-windows.md)

LINE Desktop MCP 把桌面 LINE 的常用操作接進 Codex。你可以直接對 Codex 下指令讀聊天、找訊息、發送回覆，也能把內容先留在草稿或匯出成檔案。Windows 啟用 `LINE_MCP_EXTENSIONS=1` 後共有 24 個工具；其他支援本機 MCP 的客戶端也可串接。

以下範例中的「Demo」是示意聊天室名稱，使用時請換成自己的指定聊天室。

## 1. 讀取與整理聊天

取得指定聊天室當下已載入的近期記錄，回傳日期、時間、發話者、文字與訊息類型等欄位。可以限制回傳筆數或日期，讓 AI 接著整理重點、待辦事項與需要回覆的內容。

```text
讀取「Demo」最近 20 則訊息，整理討論重點和還沒處理的事項。
```

| 工具 | 用途 |
| --- | --- |
| `get_line_chatroom_history_short` | 小範圍近期記錄，適合回覆前讀取上下文 |
| `get_line_chatroom_history_default` | 一般範圍的記錄讀取 |
| `get_line_chatroom_history_long` | 較多次向上載入的記錄讀取 |
| `get_line_chat_messages` | 結構化訊息，支援日期區間與筆數篩選 |

三種讀取大小決定向上載入的範圍，回傳仍受 `messageLimit` 限制；不代表可以直接下載完整帳號歷史。原始文字缺少發話者或日期時會保留未知狀態。

## 2. 搜尋與核對訊息

在這次取得的記錄中找關鍵字，搭配日期、發話者或訊息類型篩選。也可核對一段完整文字是否已出現在指定聊天室，避免僅憑畫面操作成功就判斷文字已存在。

```text
在「Demo」近期記錄中找「交貨」，列出日期、發話者和原文。
```

| 工具 | 用途 |
| --- | --- |
| `search_line_chat_messages` | 按字面搜尋文字，搭配日期／發話者篩選 |
| `verify_line_message` | 查找完全相同的文字，可再指定發話者或日期 |

查到相同文字代表它存在於這次取得的範圍；不能據此判斷收件者已讀或收到通知。

## 3. 發送文字訊息

可直接向指定聊天室發送文字，支援多行內容。也可將文字先放進 LINE 的輸入框，保留為草稿。

```text
傳給「Demo」：今天的資料已整理完成，我稍後補上附件。
```

| 工具 | 用途 |
| --- | --- |
| `send_message_auto` | 直接發送指定文字 |
| `send_message_manual` | 將文字放入 LINE 輸入框，保留為未送出的草稿 |

傳送模式由使用者的指令與客戶端流程決定；先提供明確的聊天室與內容。一般文字中的 `@名字` 會以文字送出，不等於 LINE 的藍色提及通知。

## 4. 管理草稿

讀取輸入框目前的內容、寫入新草稿、檢查完整內容是否寫入，或清除特定草稿。要取代既有草稿時，會核對舊值，避免把使用者剛修改的內容蓋掉。

```text
把這段回覆先放到「Demo」的草稿裡，讓我晚點繼續編輯。
```

| 工具 | 用途 |
| --- | --- |
| `get_line_draft` | 讀取目前草稿 |
| `set_line_draft` | 寫入草稿並讀回；取代既有內容時需核對舊值 |
| `clear_line_draft` | 僅清除與預期內容完全相同的草稿 |

## 5. 匯出聊天紀錄

把指定範圍的聊天記錄保存為 TXT、JSON 或 CSV。TXT 適合閱讀，JSON 保留結構，CSV 適合放進試算表整理。輸出包含讀回驗證與 SHA-256，並避免覆寫既有檔案。

```text
將「Demo」最近 30 則訊息匯出成新的 CSV 檔。
```

| 工具 | 用途 |
| --- | --- |
| `export_line_chat_history` | 按日期、文字或發話者條件匯出到新的本機檔案 |

工具需要明確的本機絕對路徑；這類匯出供閱讀與整理使用，不是 LINE 帳號還原檔。

## 6. 附件、引用與訊息操作

| 工具 | 用途 |
| --- | --- |
| `send_file_manual` | 在 LINE 的檔案選擇視窗填入指定附件；按下「開啟」時才實際上傳 |
| `stage_line_reply` | 對指定訊息準備真正的引用回覆與草稿 |
| `copy_line_message` | 複製指定訊息，並核對剪貼簿內容 |
| `translate_line_message` | 開啟 LINE 對指定訊息的翻譯操作 |
| `stage_line_forward` | 開啟指定訊息的轉傳對象選擇畫面 |

這些工具依賴 LINE 客戶端能否提供可確認的訊息與控制項。找不到唯一目標時會說明原因，讓客戶端改採視覺操作。

## 7. 聊天室導覽與工具狀態

| 工具 | 用途 |
| --- | --- |
| `get_line_capabilities` | 查看工具清單、功能分類與能力說明 |
| `get_line_workflow` | 取得指定視覺流程的操作指引，本身不執行操作 |
| `get_line_status` | 查看 LINE 視窗與 GUI 執行環境狀態 |
| `open_line_chat` | 開啟指定聊天室並確認目標 |
| `get_line_ui_state` | 讀取指定聊天室的介面狀態，必要時提供標題截圖 |
| `confirm_line_chat_view` | 對已觀察的聊天室標題建立短效確認，供後續操作使用 |
| `open_line_chat_feature` | 導向搜尋、記事本、相簿、投票、媒體、檔案、連結、貼圖或附件入口 |

## 使用範圍

維護者已在本機持續使用既有聊天讀取與訊息發送流程。新增介面工具會受 LINE 版本、語言、視窗結構與 CUA Driver 影響；不能確認目標時會回報原因。真實提及、收回、成員名單與共用內容編輯等功能，保留為需要視覺操作的流程。

詳細工具契約、並行保護和日期化驗證紀錄，請見 [Windows 擴充技術文件](windows-extensions.md)。
